## About Me

I'm **Yash Shinde**, a **Full Stack Python Developer** and the **Founder of Nyxen**.

I build software that focuses on **performance**, **privacy**, and **beautiful user experiences**.

Instead of chasing trends, I enjoy creating products that solve real problems through scalable backend systems, modern frontend experiences, and thoughtful design.

My goal is simple:
